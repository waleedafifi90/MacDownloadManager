# 08: الواجهة

المصدر: الـ resources تبعت `IDMan.exe` (105 نافذة، والقوائم). استخرجناها بـ `research/tools/pe_dialogs.py`، والنص الكامل موجود في `research/idman_dialogs.txt`.

**القاعدة:** منحاكي **الترتيب وطريقة الشغل** (وين كل شي، وشو بيصير بأي خطوة). بس الشكل منعمله بأدوات الماك وأيقونات SF Symbols. ما منستخدم أيقونات IDM ولا صوره ولا اسمه.

## 1. النافذة الرئيسية (`"Internet Download Manager 6.43"` 532×209)
- **يسار:** شجرة `Categories` (92 بكسل عرض) فيها زر `x` لإخفائها.
- **يمين:** قائمة التحميلات (`SysListView32`).
- **فوق:** شريط أزرار كبيرة، كل زر أيقونة وتحتها نص. حسب قائمة `Tasks/File/Downloads` وترتيب IDM: Add URL، Resume، Stop، Stop All، Delete، Delete Completed، Options، Scheduler، Start Queue، Stop Queue، Grabber.
- **الأعمدة** (من `View ▸ Arrange files`): File Name، Size، Status، Time Left، Transfer Rate، Last Try Date، Description. وفي كمان أعمدة اختيارية: Save Path، Referer، Parent Web Page.

## 3. رحلة إضافة تحميل
1. `"Enter new address to download"`: حقل لعنوان الرابط.
2. `"Download File Info"`: بيبيّن قبل ما يبلّش التحميل:
   - URL، و Category (مع زر `+`)، و Save As (مع زر `...`)، و Description.
   - خيار "Remember this path for ‹category›".
   - الأزرار: **Download Later**، و **Start Download**، و Cancel.
3. `"Download progress"`: نافذة لكل تحميل. **هاي اللي بتميّز IDM.**
   - العنوان: `‹النسبة›% ‹اسم الملف›`.
   - تبويبات: `Download status` | `Speed Limiter` | `Options on completion`.
   - **Download status:** الرابط، Status، File size، Downloaded، Transfer rate، Time left، Resume capability.
   - شريط تقدم، و `<< Hide details`، و Pause، و Cancel.
   - **"Start positions and download progress by connections":** شريط بيبيّن كل القطع، وتحته جدول (رقم الاتصال، النازل، المعلومات).
4. `"Download complete"`:
   - "Downloaded xx bytes"، و Address، و "The file saved as".
   - الأزرار: Open، و Open with...، و Open folder، و Close.
   - خيار "Don't show this dialog again".

## 4. نوافذ تانية (للمراحل الجاية)
- **Speed Limiter settings:** حد عام (KB/s)، بيتشغل وبيتطفى من `Downloads ▸ Speed Limiter`. وكمان في حد لكل تحميل لحاله من تبويب Speed Limiter.
- **Options:** تبويبات General، و File types، و Save to، و Downloads، و Connection (أقصى عدد اتصالات)، و Proxy / Socks، و Sites Logins، و Dial Up / VPN، و Sounds.
- **Scheduler:** على اليسار شجرة Queues، والأزرار: New queue، و Delete، و Start now، و Stop.
- **File Properties:** Type، Status، Size، Save To، Address، Description، الصفحة اللي جاي منها الملف، Referer، Login/Password، Last try.
- **Batch download، و Site Grabber، و Zip preview، و Download All Links.**
